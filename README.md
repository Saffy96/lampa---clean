# Lampa Clean v0.1

Экспериментальный плагин для очистки интерфейса Lampa от рекламных и промо-элементов.

## Что умеет

- скрывает типовые banner / promo / advert / sponsor элементы;
- следит за DOM через MutationObserver и удаляет новые рекламные элементы;
- блокирует несколько типовых рекламных хостов для fetch/XHR;
- имеет локальный API для включения, выключения и отладки;
- не вмешивается в видеопоток.

## Установка

После включения GitHub Pages добавьте в Lampa эту ссылку:

`https://saffy96.github.io/lampa---clean/lampa-clean.js`

В Lampa: Настройки → Расширения → Добавить плагин → вставьте ссылку → перезапустите Lampa.

## Отладка

`LampaClean.debug(true)` — включить отладку.

`LampaClean.clean()` — запустить очистку вручную.

`LampaClean.disable()` — отключить.

`LampaClean.enable()` — включить.

## Важно

v0.1 использует осторожный общий набор селекторов. После теста на конкретной версии Lampa можно добавить точные селекторы и рекламные домены.
